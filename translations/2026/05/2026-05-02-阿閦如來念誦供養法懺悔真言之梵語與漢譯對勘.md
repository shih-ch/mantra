## 【附註/名相對照】

- 唵（oṃ）：總攝諸佛身語意之種子音。  
- 薩嚩 / 薩斡（sarva）：一切、全部。  
- 播跛 / 巴鉢（pāpa）：罪、罪業。  
- 娑普吒 / 思普吒（sphoṭa / sphuṭa）（待考）：裂開、爆裂、摧碎。  
- 娜訶曩 / 達賀囉（dahana / dahānā）（形態待考）：燒、焚燒、燒盡。  
- 嚩日囉 / 斡資囉（vajra / vajra-）：金剛（vajra），表堅固不壞智慧與金剛杵法器。  
- 野 / 耶（-ya）：向、於、對……者（與「金剛」構成與格「向金剛者」）。  
- 娑嚩訶 / 娑婆訶（svāhā）：成就、圓滿、供養安住之咒尾語。

## 【疑點/勘誤】

1. 「pāpasphoṭa」與「pāpaṃsphuṭa」兩形，是否原為同一詞之不同傳寫，或實為「pāpa-sphoṭa / pāpaṃ sphuṭa」兩構詞，需參照梵文本與悉曇底本進一步校勘。（待考）  
2. 「dahana / dahānā」尾音與長短母音不一，可能為誦音／書寫差異，現據原文保留，不作統一改寫。（待考）
